<Warning>
  Planned. The MCP server does not exist yet, and nothing on this page is available today.
</Warning>

smartcloud plans to offer a [Model Context Protocol](https://modelcontextprotocol.io) server, so AI assistants and agents can work with a repository's smartcloud config through the same code the action and CLI use, rather than guessing at it.

This page will describe the server's tools, how to connect it, and the permissions it needs once it is built. Until then, use the [CLI](/cli) to validate and migrate configs.
