# Duration

Investigatory commits only. A routine commit carries no duration sentence and
no time trailer.

## Sources

An activity-capture tool if one is running, otherwise this session's own
timestamps. Never name the capture tool, the chat, the agent, the AI, or
waiting, anywhere in the message.

## What the window covers

This change, including blocked wait - time away or idle because you could not
progress. Time spent on another change never counts here, and the same
minutes never fund two messages.

## How to measure

1. Window start: the first edit, or the first user instruction for this
   change in this session. Window end: now.
2. If an activity-capture tool is available, query its activity summary for
   that window and use it to detect other-change work to subtract. Do not use
   active minutes alone: blocked wait on this change counts.
3. Otherwise use this session's timestamps for the same window.
4. Subtract spans belonging to another commit in this session.
5. If there is no usable window, omit the duration beat entirely.
6. Round up to the nearest half hour. 1 to 30 minutes becomes `0.5 hours`;
   31 to 60 minutes becomes `1.0 hours`. That rounding **is** the thinking,
   definition and thought allowance. Do not add extra thinking on top and
   then round again. Four minutes becoming 0.5 hours is explainable. Four
   minutes becoming 4 hours is not.
7. Write the figure as the last sentence only: `0.5 hours`, `1.5 hours`.
   Prose only. No `Time:` trailer, and no duplicate elsewhere in the body.
