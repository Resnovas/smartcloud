# Handover

Clobber file. Read it first when picking up work on this skill, and overwrite
your own section at the end of the session. It carries what is in flight, not
what happened - the history is `CHANGELOG.md`.

Overwrite only your own workstream's section, never anyone else's, and delete
the section when its work lands. Durable reference belongs in a `references/`
file rather than here: nothing in this file has an owner once its workstream
ends, so anything left behind is the first thing lost to a tidy-up.
